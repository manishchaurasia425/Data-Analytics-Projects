# 🍕 Pizza Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This Power BI project analyzes **Pizza Sales Data (January 2015 – December 2015)** to extract meaningful insights related to revenue, orders, customer behavior, and product performance.  
The dashboard supports **data-driven decision-making** through interactive and visually rich reports.

## 🎯 Objectives
- Analyze total revenue and sales performance
- Identify best-selling and worst-selling pizzas
- Understand daily and monthly order trends
- Compare sales by pizza category and size
- Discover busiest days and peak months

---

## 🛠 Tools & Technologies
- Power BI Desktop  
- Power Query (ETL)  
- DAX (Data Analysis Expressions)  
- Excel / CSV Dataset  

---

## 📊 Key Performance Indicators (KPIs)
- **Total Revenue:** 817.86K  
- **Total Orders:** 21,350  
- **Total Pizzas Sold:** 49,574  
- **Average Order Value:** 38.31  
- **Average Pizzas per Order:** 2.32

### 🔹 Best & Worst Sellers

- **Bottom 5 Pizzas** by revenue, quantity & orders

---

## 📌 Key Insights
- **Classic category** contributes the highest sales and orders
- **Large-size pizzas** generate maximum revenue
- **Friday & Saturday evenings** are the busiest
- **July and January** show peak monthly demand
- **Thai Chicken Pizza** leads in revenue
- **Brie Carre Pizza** is the lowest performer

---

## 📂 Dataset Details
- Format: CSV  
- Data includes:
  - Order date & time
  - Pizza name, category & size
  - Quantity sold
  - Revenue

## 🚀 How to Use
1. Download the `.pbix` file  
2. Open it in **Power BI Desktop**
3. Use slicers for filtering (date, category)
4. Navigate pages using dashboard buttons
